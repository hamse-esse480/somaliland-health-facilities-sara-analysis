# Somaliland Health Facilities SARA Survey 2022

## Project Overview

This project presents an Excel-based analysis of the Somaliland Health Facilities Service Availability and Readiness Assessment (SARA) Survey 2022. It explores facility distribution and selected service-availability and readiness indicators.

## Tools Used

- Microsoft Excel

## Dataset

- Dataset label: Somaliland Health Facilities SARA Survey 2022
- 348 health-facility records, according to the current project summary
- 6 regions
- District coverage: the current README's summary reports 28 districts. Verify this count against the cleaned workbook before treating it as final.

## Analysis Workflow

- Data cleaning and validation
- Descriptive summaries of facilities by region and type
- Review of selected service availability, ownership, priority needs, location, and population-served fields

## Key Findings

- **Health facilities:** 348 records across 6 regions; the current summary reports 28 districts (district count should be checked against the workbook).
- **Regional distribution:** Marodi Jeex 82, Sanaag 65, Sool 64, Togdheer 52, Awdal 51, and Saaxil 34.
- **Facility type:** Health Centers 185, Health Posts 129, Hospitals 32, and District Hospitals 2.
- **Maternal care services:** 84 facilities were recorded as providing maternal care services; 264 records had missing information.
- **TB treatment services:** 13 facilities were recorded as providing TB treatment services; 335 records had missing information.
- **Ownership:** 132 facilities were recorded as MOHD-owned; 216 records had missing ownership information.
- **Priority facilities:** 132 facilities were identified as priority facilities.
- **Priority needs:** Among priority facilities, 98 were reported as requiring medical equipment, sterilization, vaccine refrigeration, and lighting; 34 were reported as requiring lighting.
- **Location data:** Location information was missing for 216 of 348 facilities.
- **Population served:** For the 38 facilities with available population-served data, the mean was approximately 13,665, median 12,692, and range 1,513–29,000.

## Data Quality and Limitations

Missing information is substantial for several fields. For example, location is missing for 216/348 records (62.1%), maternal care information for 264/348 (75.9%), TB treatment information for 335/348 (96.3%), and ownership information for 216/348 (62.1%). These missing values limit the ability to estimate service availability or compare facilities reliably. A blank value should not be interpreted as a confirmed absence of a service unless the dataset documentation supports that interpretation.

The district count is not independently verified in this update. The earlier audit identified a 28-versus-29 discrepancy; reconcile the distinct district count from the workbook before publication.

## Project Purpose

This project demonstrates practical skills in health data management, data validation, descriptive analysis, and communicating data-quality limitations using Microsoft Excel.
